# BIN Checker 
Пользователь вводит BIN банковской карты и видит доступную информацию о нём (страна, координаты, тип карты(visa и тп), данные банка(url, телефон, сайт, город)) загруженную с https://binlist.net/ .
# Инструкция по эксплуатации
Навигация по приложению осуществляется при помощи меню, расположенного внизу экрана. Пункты меню, при нажатии на которые осуществляется переход на соответствующий экран:
- Поиск
- История
### Поиск
На этом экране можно осуществить поиск информации по карте по известному BIN номеру. После запроса пользователь видит карточку с данными. При нажатии на строку данных открывается поисковый сайт с результатами.
### История
На этом экране можно посмотреть историю запросов. При желании историю запросов можно очистить.
